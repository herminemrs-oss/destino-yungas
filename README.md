# Destino Yungas

Guía estática de las Yungas de Jujuy. Lista para Netlify.

## Publicar

1. [app.netlify.com](https://app.netlify.com) → Add new site → Import from Git
2. Elegí este repo (`herminemrs-oss/destino-yungas`)
3. Publish directory: `.` (o dejar vacío)
4. Deploy

O drag & drop de esta carpeta en [app.netlify.com/drop](https://app.netlify.com/drop)

Luego: Domain settings → Add custom domain (`destinoyungas.com.ar` + `destinoyungas.com`).
